# Установка и запуск

## Что нужно

- macOS с Safari 18 или новее
- Node.js 20+ (`node --version`)
- Claude Code с входом в подписку: запусти `claude` и выполни `/login`, если ещё не входил

## 1. Запусти мост

Мост — маленький локальный сервер. Через него расширение общается с Claude Code. Без него popup не работает.

```bash
cd claude-safari
npm run bridge
```

Должно появиться `Claude bridge listening on http://127.0.0.1:8787`. Не закрывай этот терминал, пока пользуешься расширением.

## 2. Включи режим разработчика в Safari

1. Safari → Настройки → **Дополнения** → включи «Показывать функции для веб-разработчиков».
2. Настройки → **Разработчик** → включи «Разрешать неподписанные расширения». Safari попросит пароль.

Эта галочка сбрасывается при каждом перезапуске Safari, её придётся включать заново.

## 3. Установи расширение

Выбери один из двух вариантов.

### Вариант А: быстро, без Xcode

1. Настройки → **Разработчик** → **Add Temporary Extension…**
2. Выбери папку `claude-safari/extension`.

Расширение пропадёт после перезапуска Safari, тогда добавь его снова. Плюс этого варианта: правки в коде подхватываются без пересборки.

### Вариант Б: постоянно, через Xcode

Нужен установленный Xcode. Если ставишь его впервые, один раз выполни:

```bash
sudo xcodebuild -license accept
```

```bash
xcodebuild -runFirstLaunch
```

Собери приложение и запусти его:

```bash
cd "claude-safari/safari/Claude for Safari" && xcodebuild -project "Claude for Safari.xcodeproj" -scheme "Claude for Safari" -configuration Debug -derivedDataPath ../build CODE_SIGN_IDENTITY="-" CODE_SIGN_STYLE=Manual DEVELOPMENT_TEAM="" build
```

```bash
open "claude-safari/safari/build/Build/Products/Debug/Claude for Safari.app"
```

Можно и проще: открой `safari/Claude for Safari/Claude for Safari.xcodeproj` в Xcode и нажми ▶ Run.

## 4. Включи расширение

Safari → Настройки → **Расширения** → поставь галочку у **Claude for Safari** и разреши доступ к сайтам.

Если расширения нет в списке, закрой окно настроек и открой заново (⌘,).

## 5. Пользуйся

1. Открой любую страницу.
2. Нажми кнопку расширения в тулбаре. Если её не видно: Вид → Настроить панель инструментов.
3. Выбери модель (Haiku быстрее, Sonnet умнее), напиши вопрос и нажми ⌘↵.

## Если не работает

| Что видишь | Что сделать |
|---|---|
| «Bridge is not running» | Запусти `npm run bridge` (шаг 1) |
| Расширения нет в списке Safari | Проверь галочку «Разрешать неподписанные расширения», перезапусти приложение Claude for Safari |
| Ошибка про вход или авторизацию | Запусти `claude` в терминале и выполни `/login` |
| Ответ не приходит долго | Это нормально для первого запроса: Claude Code стартует несколько секунд. Haiku отвечает быстрее |
